Guia Tailwind

A Ana tem uma padaria, um site de três páginas e um problema: tudo o que ela escreve no HTML sai na tela sem graça nenhuma, um bloco de texto atrás do outro, colado na borda. Este guia ensina o Tailwind do começo — o que é uma classe, o que p-4 faz, como ficar lado a lado, como mudar no celular e no escuro — até o dia em que a página dela parece desenhada por alguém. Escrito em português, para quem nunca programou.

Como este guia funciona
  • 144 aulas, uma ideia por aula, na ordem em que se aprende de verdade.
  • Toda caixa "Experimente" compila o seu HTML com o Tailwind v4 de verdade e mostra o CSS que o navegador aplicou — não é uma imagem do resultado.
  • O CSS do painel é lido do navegador: se o valor mudou, o número que aparece é o valor real.
  • Não precisa instalar nada para começar: as caixas já trazem o compilador.

1. Para quem é

Para quem nunca escreveu uma linha de código e quer que a página fique bonita. O guia não supõe que você saiba HTML ou CSS: cada peça aparece quando é necessária, explicada na hora, com a analogia antes do nome técnico. Se você já é programador, o Nível 1 vai parecer devagar — é de propósito. A leitora que este guia atende é a Ana, e a Ana ainda confunde margem com respiro.

Se você já escreveu CSS na vida, comece pela aula Tailwind x CSS, na Referência: ela mostra a mesma caixa nas duas linguagens, lado a lado, e aponta o que muda de verdade — não existe arquivo de estilos para sincronizar, e o nome da classe já diz o que ela faz.

2. As primeiras classes, agora

Este é o mesmo cartão que a primeira aula monta. Leia o HTML, clique em Rodar e veja o que o navegador respondeu. O Tailwind que compila esta caixa é o mesmo que você vai usar no seu projeto — a build oficial, rodando aqui dentro.

Missão: o cartão da padaria está sem respiro e com canto reto. Deixe 24 px de respiro interno e cantos de 12 px (as classes p-6 e rounded-xl).

<div id="alvo" class="bg-amber-100 text-amber-900">
  <strong>Pão quentinho</strong>
  <p>Sai do forno às 6h.</p>
</div>
background-color: oklch(0.962 0.059 95.617)
color: oklch(0.414 0.112 45.904)

<div id="alvo" class="bg-amber-100 text-amber-900 p-6 rounded-xl">
  <strong>Pão quentinho</strong>
  <p>Sai do forno às 6h.</p>
</div>

O painel mostra só o que as classes mudaram. padding: 24px é o respiro que você pediu; border-radius: 12px é o canto arredondado. Nenhum desses números foi escrito à mão: eles saem do CSS que o Tailwind gerou e o navegador aplicou.

3. O que você vai construir

No fim do Nível 1, a Ana tem a página da padaria com cartão de preço, lista de pães e um aviso que só aparece no celular. No Nível 2, a página ganha cara de produto: botão com estado de foco, card com sombra, formulário de encomenda, tabela de horários, menu que abre, tema escuro que respeita a preferência do sistema e uma animação discreta quando o mouse passa.

No Nível 3, o assunto deixa de ser "fazer bonito" e vira "fazer durar": instalar com npm, entender o arquivo de CSS que o Tailwind gera, criar as suas cores com @theme, publicar só o CSS que a página usa e descobrir por que uma classe "não pega" quando o nome é montado por código.

4. Como estudar

Uma aula por vez, na ordem, com o editor aberto. Ler sobre classe não ensina classe: editar a caixa e ver o painel mudar, sim. Depois de cada aula, refaça o exercício no seu próprio arquivo — o index.html da sua pasta de estudos serve — e confira no navegador com o botão direito → Inspecionar. É o mesmo olhar que o painel do guia treina.

Não adivinhe: leia o CSS computado

Quem começa tenta descobrir o resultado olhando o código. O caminho certo é o contrário: mudar, rodar e ler o valor final. A aba Computed do navegador e o painel das caixas mostram o mesmo número — e é ele que decide como a página aparece.

5. O que este guia não é

Não é a documentação oficial: para a lista completa de utilidades existe o site do Tailwind, e a Referência aponta o caminho. Não é um curso de design: as aulas ensinam a executar uma decisão, não a tomar todas elas. E não é um curso de JavaScript: o guia usa HTML e as classes; quando um componente precisa de clique de verdade, a aula diz isso com todas as letras e mostra o mínimo necessário.

6. Resumo

  • 144 aulas em cinco níveis, da primeira classe ao CSS publicado em produção.
  • Toda caixa compila o HTML com o Tailwind v4 de verdade e mostra o CSS computado.
  • O caminho é sempre: escrever a classe, rodar, ler o painel, ajustar.
  • Nada de instalar para começar: as caixas já trazem o compilador.
  • Um projeto por nível, com a página da padaria crescendo junto com você.
